# Transmissive Optical Switch: Course Project

[Portfolio home](README.md) · [All projects](CATALOG.md)

An optoelectronic course project using a light source and phototransistor to control switching behaviour.

**Technologies:** Optoelectronic sensing · Microcontroller logic · Simulation

**Status:** Course report available; the original project files and later hardware revision need consolidation.

## Problem

An optical path can provide a contactless signal for switching a load. The project connects optical detection, signal conditioning and controller behaviour.

## My work

- Documented the light-source and phototransistor detection arrangement.
- Prepared the system design, software flow and simulation discussion.
- Included a controller-program listing in the course report.

## Evidence and results

The 15-page report is titled Transmissive Optical Switch System Design. Its appendices contain an 8051-style assembly listing.

## Scope and limitations

The course report and a later STM32 implementation mentioned in my CV must be distinguished. This case currently describes the documented course version only; it does not claim a verified STM32 code release or newly tested hardware.
