# Changsha Rice-noodle Shop Map

[Portfolio home](README.md) · [All projects](CATALOG.md)

A map-based discovery interface with ranked shop lists, detail views and a Python geocoding workflow.

**Technologies:** React · TypeScript · Vite · Leaflet · Python

**Status:** Local implementation; a public deployment has not been verified.

## Problem

A long list of restaurant recommendations becomes more useful when readers can understand where the shops are and navigate between the ranking and the map.

## My work

- Built map, list and detail components with desktop and mobile layouts.
- Added map markers, selected-shop navigation and location-aware detail interactions.
- Used Python scripts to process location data and perform geocoding.
- Represented shop data with TypeScript types, including approximate-location and source-detail fields.

## Evidence and results

The inspected local dataset contains 207 ranked entries and seven additional entries. The source includes the map, list and shop-detail components.

## Scope and limitations

Ranking content and photographs have third-party sources and are not claimed as my original research. A public release requires source/asset permission checks and removal of embedded API credentials. The dataset and application source are not distributed in this portfolio.
