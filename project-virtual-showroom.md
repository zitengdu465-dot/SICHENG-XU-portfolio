# Interactive 3D Product Showroom

[Portfolio home](README.md) · [All projects](CATALOG.md)

A Three.js showroom prototype with product inspection animations, material detail and structured product information.

**Technologies:** Three.js · JavaScript · WebGL · JSON · esbuild

**Status:** Interactive prototype.

## Problem

A physical exhibition stand offers a useful spatial way to discover products. The project explores how to bring that interaction into a browser while keeping product information separate from scene code.

## My work

- Developed modular scene, display-unit, product-geometry, material and post-processing code.
- Implemented product selection, pickup and return animations, information cards and course entry points.
- Modelled spouted pouches and display fixtures, with lighting, roughness, normal textures and depth-of-field effects.
- Separated product, series and course records into JSON data files.

## Evidence and results

The local version includes six source modules, a bundled application and desktop/mobile preview captures. The project record documents earlier interaction checks; those browser checks were not repeated for this portfolio preparation.
